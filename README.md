# Сайт «Экспогород — городской интерес»

Статический сайт без сборки. Карта использует MapLibre и OpenFreeMap; остальные страницы работают без сторонних библиотек. Для GitHub Pages публикуются только файлы этой папки. Запуск: `python3 -m http.server 8765 --directory site --bind 127.0.0.1` из корня проекта.

Публичный сайт: https://makeevarch-lgtm.github.io/expogorod-survey/ . В `config.js` установлена точная публичная ссылка Яндекс Форм. Страница загружает форму только по нажатию кнопки; отдельная ссылка позволяет открыть анкету при проблеме со встраиванием. При отключённом JavaScript доступна прямая ссылка. Административная ссылка не принимается.

Ответы и личные данные не сохраняются в GitHub. Форма и её экспорт управляются в Яндекс Формах. Публичная публикация сайта и анкеты проверена 10 октября 2026 года. В публичный репозиторий отправляются только файлы сайта: `index.html`, `analytics.html`, `style.css`, `app.js`, `config.js`, `results.js`, `charts.js`, `charts.css`, `results.json`, `assets/mark.svg`, `assets/icons.svg`, `.nojekyll`. Приватные материалы и исходные ответы не публикуются.

Графика `assets/mark.svg` и рисунок в HTML созданы для этого проекта; это декоративная схема, не карта участка. Используются системные шрифты. Фотография `assets/author.png` предоставлена автором проекта.

Версия 2.1: форма настроена в цветах сайта, встроенная область ограничена по ширине. Высота подстраивается через штатный протокол сообщений Яндекса с проверкой origin и источника; при отсутствии сообщения остаётся резервная высота.

Дизайн 2.2: оформление по пользовательскому архитектурному подрамнику — чёрные линии и заголовки, серые поля, сиреневый, розовый и зелёный акценты. Системный стек Helvetica Neue/Helvetica/Arial. Декоративная схема и знак созданы для страницы; сам PDF, фотографии и карты из него не опубликованы. Происхождение и параметры описаны локально в `docs/design-reference.md`. Содержание анкеты остаётся в версии 2.1.

## Результаты и графика (2.3)

Публичные файлы дополнены `results.js`, `results.json`, `assets/icons.svg`. В JSON только проверенные агрегаты; исходный CSV остаётся в `private/`. Метод обновления: `../docs/network-analysis.md`. На сайте есть экспорт текущей схемы в самостоятельный SVG для размещения в проекте. Знак и иконки — собственная векторная графика.


## Отдельная аналитика (2.7)

`analytics.html` открывается вкладкой «Аналитика» в меню. Старые ссылки `/#results` перенаправляются на неё. Диаграммы используют тот же проверенный results.json: число выборов, желание приехать, состав всех отмеченных вариантов, матрицу совместного выбора и сеть. Доля в круге интересов считается от общего числа отметок, а не от количества анкет. Главная страница не загружает результаты.

## Понятный вход и интерактивное исследование (3.0)

Главная поясняет дипломный проект и выделяет опрос как основное действие. Ниже —
переходы к результатам и территории, описание исследования и блок Елисея Макеева
с портретом и ссылкой `https://t.me/makeev_architect`. Новый знак развивает собственную
метку экспериментального кольца. Портрет сохранён без изменения внешности.

Аналитика начинает с вычисляемых наблюдений и отдельно подписанной проектной
гипотезы. Выбор узла или названия интереса подсвечивает сочетания; кнопка сброса,
порог связей и клавиши Enter/Space/Escape доступны без наведения мышью. Три
опциональных диаграммы доступности используют отдельные основания из `mobility`:
время поездки, транспорт, пеший путь. Старые срезы без этих полей поддерживаются.

Карта предлагает три ракурса существующего положения: Москва, кольцо, железнодорожные
связи и станция Щербинка. Новые проектные объекты или подтверждённые пешеходные
маршруты на карте не изображаются. Таблица и фильтры сохранены.

`motion.js` — необязательное улучшение появления секций. Содержимое доступно без
JavaScript, а `prefers-reduced-motion` отключает движение. Исходные ответы, ID и
свободный текст остаются вне сайта. Ежедневный пересчёт тем же скриптом обновляет
в том числе доступность и наблюдения, без генерации текста внешним ИИ.
